# FNF_Materials
FNF (Friday Night Funkin') 関係で作成した物を保管・配布しています。  
以下を管理しています。  
 - プロジェクトファイル : FLP / FLM / MIDI  
   - 楽曲のVocalを再現したもの  
   - 楽曲のプロジェクトファイル (FLPのみ)  
    
 - キャラクターボイスの再現  
   - Chromatics : .wav / .fst  
   - DirectWave : .dwp / .dwb  
   - SoundFont  : .sf  


# プラグイン
以下のプラグインのインストールをお願いします。ほとんどのFLPに用いられています。  
 - OTT

---

基本的にストックプラグインとOTTのみですが、使うかもしれないものとして  
 - khs製品　（主にKilohearts Essentials）
があります。  
他に必要な物が増えた場合、順次追加していきます。  


# ダウンロード  
個々ではそれぞれのファイルにアクセスし、ダウンロードすることをおすすめします。  

---

一括でのダウンロードはGitでの操作を推奨します  
```
git clone git@github.com:user-fox79/FNF_Music_Materials.git
```  
などでクローン、  
ただLFSを利用しているので、FLPはバイナリでダウンロードされます
実体は
```
git lfs pull
```  
もしくは  
```
git lfs fetch
git lfs checkout
```  
でダウンロードできます
