# FNF_Materials
FNF (Friday Night Funkin') 関係で作成した物を保管・配布しています。  
以下を管理しています。  
 - プロジェクトファイル : FLP / FLM / MIDI  
   - 楽曲のVocalを再現したもの  
   - 楽曲のプロジェクトファイル (FLPのみ)  
    
 - キャラクターボイスの再現  
   - Chromatics : wav / fst  
   - DirectWave : dwp / dwb  
   - SoundFont  : sf
